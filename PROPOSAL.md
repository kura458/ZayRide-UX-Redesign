\# ZayRide Passenger App — UI/UX Redesign Proposal



\## 1. Project Title



\*\*Improving the User Experience of ZayRide Passenger: An Android UI Redesign\*\*



\## 2. Background



ZayRide is an Ethiopian ride-booking service designed to connect passengers with drivers. A passenger ride-booking experience involves several important steps, including choosing a pickup location, entering a destination, reviewing ride options, and confirming a request.



This project proposes an improved Android user interface for the ZayRide Passenger application. The redesign will focus on clarity, simplicity, consistency, and accessibility.



\## 3. Problem Statement



A ride-booking interface should help passengers understand what to do at every stage of the booking process.



If important information is difficult to locate, buttons are unclear, or ride options are poorly organized, users may experience confusion when trying to request transportation.



This project will address these potential usability challenges through a redesigned interface. These are design concerns to investigate and improve, not confirmed defects in the original application.



\## 4. Proposed Solution



The proposed solution is to create a simple and visually consistent Android interface using Android Studio XML layouts.



The redesign will provide:



\- Clear headings and readable text.

\- Consistent colors, buttons, and spacing.

\- Easy-to-identify pickup and destination fields.

\- Organized ride categories and estimated fares.

\- Clearly visible primary actions.

\- A simple navigation structure.



\## 5. Main Objectives



1\. Improve the visual organization of the passenger interface.

2\. Make the ride-booking process easier to understand.

3\. Improve text readability and visual hierarchy.

4\. Apply accessibility principles, including appropriately sized touch targets.

5\. Create consistent Android layouts using XML resources.

6\. Demonstrate the proposed interface through an Android Studio prototype.



\## 6. Scope of the Redesign



The project will focus on three core screens.



\### Screen 1: Welcome Screen



\*\*Purpose:\*\* Introduce the application and help the passenger begin.



Planned elements:

\- ZayRide branding.

\- Welcome message.

\- Short description.

\- Get Started button.



\### Screen 2: Home / Find a Ride



\*\*Purpose:\*\* Allow the passenger to provide journey information.



Planned elements:

\- Passenger greeting.

\- Map placeholder.

\- Pickup location field.

\- Destination field.

\- Find a Ride button.

\- Simple bottom navigation.



\### Screen 3: Choose Your Ride



\*\*Purpose:\*\* Help passengers review ride options before confirmation.



Planned elements:

\- Pickup and destination summary.

\- Available ride categories.

\- Estimated fare for each option.

\- Estimated total fare.

\- Confirm Ride button.



\## 7. Expected Impact



The proposed redesign is expected to:



\- Make important information easier to find.

\- Improve the visual consistency of the interface.

\- Help passengers understand the booking sequence.

\- Improve readability on Android devices.

\- Demonstrate practical application of UI/UX design principles.



These expected benefits will need user testing to confirm.

\## 9. Project Limitations



This project is a static UI prototype. It does not implement:



\- Real-time GPS or map services.

\- Actual driver matching.

\- Live ride booking.

\- Payment processing.

\- Driver tracking.

\- Backend database integration.



The original Passenger application was evaluated using archived screenshots and publicly available information because a working installation was not available for direct testing.



\## 10. Conclusion



This proposal aims to improve the presentation and usability of the ZayRide Passenger interface through a focused Android UI redesign.



By concentrating on the welcome, ride-search, and ride-selection screens, the project will demonstrate how visual hierarchy, consistency, readability, and accessibility principles can be applied to a practical Ethiopian transportation application.
